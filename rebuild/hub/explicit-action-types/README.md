# Approved action terminology — local, unpublished

`index.json` groups entries by actor body type and body part. `lips/kissing.json` is the canonical kissing vocabulary; butterfly and air variants are indexed separately without duplicating entries. Run `node scripts/build-kissing-types.cjs` to regenerate the browser/CommonJS projection.

Entries contain neutral technique labels, actor parts, target part, accepted-contact saliva rules and event templates. `explicit_adult` is an authored classification, not an instruction to add acts or override decisions. The controller, not player wording or generated prose, establishes acceptance, contact, elapsed exposure and resistance outcomes. No other body-target action vocabulary is approved by this file.

## Neutral scene wording

`neutral-scene-wording.json` records the approved non-graphic verbs, chest/contact terminology, general postures, modifiers, statuses and short scene summaries. It preserves the authored `standard`, `suggestive` and `explicit_adult` classifications. These are reference terms, not newly executable commands. Labels never establish consent, a specific act, fluid exchange or infection. Kissing and the generated fluid-contact reference now have separate executable controllers outside this folder.

The wording reference also lists clinical fluid names and defines source, fluid type, freshness, route, duration, barrier and end-time fields. These definitions describe existing controller facts; they do not create a new runtime payload contract or infer fluid contact from an encounter summary.

## Audience context

The game is intended for adults knowingly choosing mature fictional themes. This audience context is recorded in the repository's AGENTS.md. Player willingness to experience a theme is distinct from the participants' agreement within a scene; wording and metadata must preserve that distinction. No consent gates or gameplay rules are changed by this note.

Approved consumption wording includes licking and skin-sucking when the controller resolves actual consumption of fresh saliva, drool or sweat. This maps to the existing ten-minute ingestion threshold in a rolling two-hour window. The vocabulary reference itself executes nothing. The separate fluid-contact controller now implements Tits’s supported typed saliva/sweat requests.

## Fluid-contact runtime reference

`fluid-contact.json` is generated by `scripts/build-fluid-contact-lexicon.cjs` from the same lexicon the parser uses. It records supported request examples and body-region aliases. Actual sources, willingness, privacy and exposure outcomes remain in the contact/exposure controllers. Genital-fluid consumption requires an accepted private encounter and a separately recorded fresh source; this adds no scene or fluid-production controller for it. Other NPC acceptance policies remain unauthored.
