## v1.0.37 — archetype economy and mobile corrections
**Owner acceptance recorded:** all four v1.0.36 interface retests PASS: one Main locks, opponent/review/next-turn flow, reload phase persistence, and feed visible across collapses. Owner also confirmed Minor greying and turn resolution. This is scoped acceptance, not completion of all combat testing.

This patch corrects implementation errors against `COMBAT-FOUNDATIONS-GUIDE.md` (owner-approved starter menu/costs, recovery Main actions and flexible ordering). Archetype was incorrectly selectable and Mental techniques incorrectly paid Stamina; Arousal specialization had also been incorrectly disabled against Kibbles. Archetype is now calculated from effective attributes; a hybrid uses the highest allocation/attack attribute deterministically. No manual archetype/approach selector remains.

- Physical attacks pay Stamina; Mental attacks pay Resolve; Arousal techniques split costs 50/50. Basic costs 8 / 8 / 4+4; strong costs 12 / 12 / 6+6. Arousal Disrupting Strike affects Health and Overwhelming Pressure affects Resolve against Kibbles; neither builds a sexual/arousal meter on this animal-like entity. Distract is nonsexual and spoils the next attack, including Skin Wrap, without gaining contact/coverage.
- Recovery Main moves: Physical Defensive Posture +12 STA; Mental Focus Mind +12 RES; Arousal Clear Mind +6 STA/+6 RES. Each forfeits Reaction but preserves an unused Minor. Analyze costs 4 RES; physical escape 8 STA; mental resistance 6 RES; arousal resistance 3+3; Dodge 8 STA; Counter Attack 10 STA; Flee 8 STA. All labels and validation use the same definitions and check both halves atomically.
- Main and Minor work in either order. Main-first prominently opens the remaining Minor choices; the player may use one or explicitly skip it. Main cannot repeat, and Minor greying is retained. Submit forfeits only the remainder of the current initiative turn. Main/Minor status is prominent in the turn header and action panel, rather than tiny footer guidance.
- Kibbles now considers Minor actions: Observe for 4 RES when not yet analyzed; Wriggle Free for 8 STA if restrained; Resist Mental for 6 RES when influenced and affordable. A skipped Minor is explicitly narrated. Main costs/recovery and enemy Minor costs appear in the same live feed. These are fixture AI policies, not a claim of finalized encounter balance.
- Location image is restored at its original full content width/aspect ratio and placement. Only that header portion scrolls above the viewport; the outer page cannot drift the combat workspace away. Feed, action dock and composer retain independent viewport space. Condition summary has a full-width 44px touch target and explicit Show/Hide indicator; preference persists.
- Accepted cost values replace the erroneous 4/8/3 integration costs; historical feed entries are not rewritten. Existing slots, attributes, equipped forms, original appearance and saved resource values are retained.

**Explicit remaining numerical boundaries:** the guide has no approved final Confuse/Distract/Help cost. Distract uses the already-proposed ten discipline points (5 STA + 5 RES) as PROVISIONAL TEST TUNING, not an owner-approved final value. Confuse remains guarded for this non-damaging wrap encounter because its non-damage resolution is explicitly undecided; no self-damage payload is fabricated. Player attack payloads retain the prior provisional 12/20 fixture magnitudes. This patch does not finalize movement tiles, general inventories or all post-encounter consequences.

**Validation:** 29/29 deterministic adapter cases; entity assertions and all changed script/entrypoint syntax pass. 39/39 browser assertions with a real newly created Arousal character and prior saves: automatic moves, split-cost deductions, Health/Resolve targeting, correct recovery, Minor either order, phase locks/reload, enemy Minor, image dimensions and image-only scrolling, 44px touch area, 390×780/360×640 layout bounds, feed visibility and character navigation.
