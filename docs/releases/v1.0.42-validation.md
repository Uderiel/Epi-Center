### Scope and unresolved design

- Body descriptions from legacy BELLA_FINAL74/equipment67; newer owner-approved resources, ten attributes and no-seam removal rules take precedence over obsolete legacy values/mechanics.
- Form-versus-Kibbles remains a Dev test, not a new world opponent. Full target encasement resolves that fixture without inventing another mastery award. No multiplayer public identity broadcasting is implemented; the local current-form field already reports Kibbles.
- Existing partial-anatomy restriction thresholds (75%) remain provisional. This release does not author new damage curves, form autonomy schedules, high-influence thresholds, resource regeneration or rarity upgrades.
- Help lane has no terrain/obstacles, so movement itself has no roll or resource charge. These are fixture assumptions, not approved universal movement balance. Call uses a fixture Minor; actual-world help timing and helper actions still require definition. Arrival records a bystander opportunity only. World location/quest triggers are not added.
- Dog treats come from the explicit Dev grant until the Cherished Touch shop is implemented. Human inventory use on the carried unmastered form grants mastery without forcing equip; combat feeding completes/equips as an encounter outcome. Already canine handling requires a future authored helper route.
- A defeated form retains zero in the exhausted pool by design. Release restores the underlying post-combat character; no hidden healing is added to make that form immediately combat-ready. Dev resource reset remains an explicit QA action.
