## v1.0.47 — full map names, shared world clock and Hub day/night artwork

Map tiles now show the same full names as Path (for example **Central Hub NW** and **Central Hub Spire**). Removed the owner-reference numbers from player-visible tiles; internal reference numbering and Path geography remain unchanged.

Implemented the supplied daytime/nighttime collages as eighteen individually extracted location images. Both use NW/N/NE; W/Spire/E; SW/S/SE. Every exported image is 1100×733, with collage gutters removed and aspect-preserving crops rather than stretching. The West café sign and East Burke's Sweets sign stay with their correct locations. Play and fullscreen artwork select from the same location/clock resolver.

Restored the temporary action-driven clock from the audited v0.8.84 source: new saves start Day 1 at 09:00; successful route steps cost 8 min; inspection/ordinary short Location text actions 1 min; conversations 2 min; route survey 5 min; Wait one hour 60 min.
