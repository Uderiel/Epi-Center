# Footwear narration grounding

v1.0.118 freezes the recovery result before requesting narration: opposed-check outcome, consolidation, before/after binding, progress and Resolve, actual mastery/release flags and sensory context. The exact receipt remains separate from qualitative prose. Failed Common checks at completed progress can still consolidate binding; no roll mechanics changed.

Experience, world-event and footwear narration share a restricted original-player viewpoint. They receive no generated conversation history. The wearer is a separate person whose mind is unaffected. Actual new shelf placements record activity/time; unknown legacy placements are not reconstructed. No material is inferred from earlier generated text.

A shared validator rejects known contradictions in identity, player emotions, mechanics, lighting, invented props/material and unsupported placement history. It requests one correction, rechecks scene/save identity, then preserves the recorded fallback if correction fails. This is bounded validation of known failure patterns, not a guarantee against every possible hallucination. All narration actors are stateless; ordinary NPC dialogue keeps its existing history.

Regression cases include the owner’s three reported passages, precise 95/100/64 to 90/100/61 recovery, all three narrator routes, rejected prose never displayed/saved, failed correction fallback and stale scene rejection. Tests use no paid provider requests or owner saves.
