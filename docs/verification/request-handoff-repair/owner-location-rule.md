# Eve projection — confirmed owner rule

Eve can appear as a hologram at Central Hub Spire and all eight surrounding Central Hub areas: N, NE, E, SE, S, SW, W, NW. Outside that region she communicates remotely. The existing player-guide route already enumerates these nine location IDs. The Applewood exterior test was outside this region; its packet correctly marked hologram projection unavailable. New dialogue validation uses that actual packet mode and permits projection when available. This is a game-side check; no worker deployment is needed.
