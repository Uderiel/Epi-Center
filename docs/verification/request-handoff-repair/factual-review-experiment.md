# Read-only factual review experiment

Existing live replies still invent unsupported facts despite correctly supplied state. Evaluate whether a short independent fact-review role catches three captured failure types (premature service, outside-range hologram, unsupported foot dimensions) without rejecting matched valid controls. One paid request, six independently judged candidates in shuffled order; expected answers are withheld from the request. Same v10 worker/internal classifier framing, no game controllers or owner saves. No new worker or gameplay pipeline change. No extra normal-play call/cost is introduced. Any later product integration would need an explicit design review because it changes normal-turn cost/latency and may still make errors.

Use the existing8-call/$0.25 follow-up ceiling with the old uncertain upper reservation retained. This small experiment is not proof of general factual verification, and must not replace full real dialogue acceptance.

Review limitation: one proposed positive control mentioned heels/pressure without supplying its supporting facts. That control cannot support a rigorous aggregate accuracy score. The demonstrated missed hologram and coffee contradictions still show that this experiment is not a reliable automatic acceptance checker.
