# Cursed-object worn exposure

Owner direction (November 4, 2026): worn game time is part of cursed-object influence. This supersedes v1.0.57’s pending trigger choice. Current generic adapter: `rebuild/hub/cursed-exposure.js`. Each object supplies its own interval/gain; rates must remain entity data, not Kibbles defaults.

Erin’s initial implementation tuning: five influence points per sixty actual worn game minutes. This retains the legacy five-point exposure magnitude while using the newly selected elapsed-wear trigger. The owner has not separately approved this numeric rate; tune explicitly with acceptance feedback. It is independent of physical stage progression, works after stage23, preserves a saved partial interval and updates canonical internal influence without resetting earned progress. No retroactive backfill is inferred from an old save.

Equipped curse exposure is an ongoing external source of pressure, so it can raise zero influence. Zero influence still prevents the consciousness from imposing an activity or restoring influence through a forced action; it is not immunity to continuing exposure from an unmastered cursed item that remains worn. Removing or storing the heels pauses worn minutes and enables existing heels-off Resolve recovery. Re-equipping resumes the saved remainder. Permanent mastery stops exposure; a canine overlay does not accrue Erin exposure. All values cap at100; mastery progress, identity, original attributes, resource balances and quest rewards are unaffected.

The game clock must supply elapsed minutes once for the actual action. No gains from rendering, free object navigation, direct questions without elapsed time, offline time, or an arbitrary number of words. An ordinary two-minute conversation contributes two elapsed worn minutes, not an extra dialogue-trigger grant. A one-hour Wait contributes sixty worn minutes regardless of its separate two/three physical changes. An eight-hour physical sleep contributes its actual duration if the unmastered curse remains worn.

Existing internal resistance/escape costs, cadence and mastery gates remain authoritative. Kibbles remains a living form and does not inherit this cursed-equipment accumulator. Tests cover partition invariance, save/reload, removal/mastery, zero bootstrap, cap, progress/resource preservation and configurable per-object intervals.
