# Canine physical input and observed responses

v1.0.121 fixes the early canine composer handler that intercepted physical inspection before normal inspection routing. Plain and starred inspection now dispatch to the actual existing inspect action. Observable panting and offered licking are recognized signals, with explicit local target resolution. Private Form input goes directly to private form dialogue and remains private. Negations, imagined actions and unspoken thoughts do not turn into public signals.

A Nadia-directed sniff no longer enters Dart’s close-greeting acceptance route. Ordinary nearby scent investigation is separate from accepting a close sniff offer; offers/barriers/identity checks still guard actual close contact. Licking remains an offered physical attempt with the recipient response separate, not assumed contact or permission. Unknown physical actions are not arbitrarily executed by model text.

Human ambient conversations exclude animal actors. Outdoor human small talk no longer uses the Priya/Nadia office script. Dart’s recorded events get a dedicated adult-male-Doberman narrator; known fox/human-work dialogue errors receive one correction before fallback. Observed canine expression is explicitly marked nonverbal in NPC context, with only actual signals exposed.

Regression tests use the actual composer, including AI on/off, raw/starred pant/inspection, Nadia sniff/lick, combined pant-and-lick, distant Dart sniff, private Bella thought, ambient exclusion and reload. Synthetic saves only, no paid provider calls or owner save changes.
